# 统一命令级取消路径验证模板

日期：2026-05-05

## 使用说明

此模板为 `TB`、`DFC`、`SyncNow` 三类命令提供统一的验证记录格式。
每条命令必须覆盖 8 条路径：正常、空输入、格式错误、取消、失败、恢复、重复执行、UNDO。

填写时，每条路径的结果栏填 `PASS` / `FAIL` / `SKIP`（需附原因）。
